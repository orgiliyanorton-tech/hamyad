# هم‌یاد — یادداشت شخصی با Next.js

پنل فارسی راست‌به‌چپ در `/admin`، ورود با ایمیل و رمز، ساخت، ویرایش، حذف و جست‌وجوی یادداشت‌، با Supabase Auth و Postgres.

## راه‌اندازی

1. یک پروژه در [Supabase](https://supabase.com/dashboard) بساز. در **SQL Editor** محتوای `supabase/schema.sql` را یک بار اجرا کن.
2. ورود با ایمیل و رمز را فعال نگه دار. در **Authentication → Users** حساب شخصی‌ات را با ایمیل و رمز قوی بساز و کاربر را تأیید کن. در تنظیمات Auth ثبت‌نام عمومی (**Allow new users to sign up**) را خاموش کن؛ برنامه هم فرم ثبت‌نام ندارد.
3. فایل `.env.example` را به `.env.local` کپی کن. آدرس پروژه و کلید عمومی `sb_publishable_…` را از Connect یا Project Settings وارد کن. هرگز کلید Secret یا `service_role` را در متغیرهای `NEXT_PUBLIC_` نگذار.
4. با Node.js 22 یا جدیدتر در پوشهٔ پروژه اجرا کن:

   ```sh
   npm install
   npm run dev
   ```

   برای آزمایش محلی به `http://localhost:3000/admin` برو. برای دسترسی از همهٔ دستگاه‌ها، پروژه را روی یک میزبان Next.js مانند Vercel منتشر کن، همان متغیرهای عمومی را قبل از بیلد در تنظیمات میزبان بگذار و با همان حساب وارد آدرس HTTPS شو. `localhost` روی بقیهٔ دستگاه‌ها همان دستگاه را نشان می‌دهد، نه رایانهٔ تو.

## همگام‌سازی و حریم خصوصی

- فقط یادداشت ذخیره‌شده همگام می‌شود. وقتی صفحه باز و قابل مشاهده است، تقریباً هر ۱۲ ثانیه، و همچنین هنگام بازگشت به تب، اطلاعات تازه دریافت می‌شوند. دکمهٔ «به‌روزرسانی» دریافت را فوری می‌کند. برای ذخیره و همگام‌سازی اتصال اینترنت لازم است.
- ذخیره و حذف بر اساس شمارهٔ نسخه انجام می‌شود. اگر دستگاه دیگری همان یادداشت را تغییر داده باشد، پیش‌نویس بازنویسی نمی‌شود و می‌توانی آن را به صورت کپی ذخیره کنی. پیش‌نویس محلی بعد از بستن یا بازخوانی صفحه نگه داشته نمی‌شود.
- کد پنل در مرورگر اجرا می‌شود. سیاست‌های سطح سطر در خود دیتابیس دسترسی کاربران را به یادداشت‌های همان حساب محدود می‌کنند؛ مسیر `/admin` به‌تنهایی یک کنترل امنیتی نیست. این پروژه رمزنگاری سرتاسری ندارد.
- فونت رابط اول IRANSansX و بعد Vazirmatn است. پیش از انتشار عمومی شرایط `public/fonts/IRANSansX-License.pdf` را بررسی کن. اگر مجوز وب مناسب نداری، دو فایل `IRANSansX-*.woff2` و دو تعریف IRANSansX را از `app/styles.css` حذف و Vazirmatn را اول قرار بده؛ مجوز آن کنار فایل فونت است.

آزمایش پیشنهادی: با یک حساب روی دو دستگاه وارد شو، در اولی یادداشتی ذخیره کن و در دومی بعد از یک چرخهٔ همگام‌سازی آن را ببین. همان یادداشت را روی هر دو تغییر بده و بررسی کن دستگاه دوم پس از ذخیرهٔ دستگاه اول نسخهٔ جدید را بازنویسی نکند.
