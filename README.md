# Hamyad (`همیار`)

یک اپلیکیشن وب ساخته شده با **Next.js** برای مدیریت و پیشبرد کارها و همکاری‌ها.

## ویژگی‌ها (Features)

* ساخته شده با معماری مدرن **Next.js**
* رابط کاربری فارسی و راست‌به‌چپ (`RTL`)
* ساختار ماژولار و قابل توسعه برای افزودن قابلیت‌های جدید

## نصب و راه‌اندازی (Installation & Getting Started)

پیش از نصب و راه‌اندازی، مطمئن شوید **Node.js** روی سیستم شما نصب است.

1. مخزن را کلون کنید:

```bash
git clone https://github.com/orgiliyanorton-tech/hamyad.git
cd hamyad
```

2. وابستگی‌ها را نصب کنید:

```bash
npm install
```

یا با yarn / pnpm:

```bash
yarn install
```

```bash
pnpm install
```

3. سرور توسعه را اجرا کنید:

```bash
npm run dev
```

سپس آدرس [http://localhost:3000](http://localhost:3000) را در مرورگر خود باز کنید.

## اسکریپت‌ها (Scripts)

* `npm run dev` — اجرای پروژه در حالت توسعه
* `npm run build` — ساخت نسخه نهایی پروژه برای تولید
* `npm run start` — اجرای نسخه ساخته‌شده
* `npm run lint` — بررسی کدها با ESLint
